# Les Premières Nations du Québec 🪶

Série complète d'articles éducatifs sur les **11 Premières Nations et les Inuits du Québec**.

🌐 **Site web** : https://lucie-app-5fea0268.base44.app  
📘 **Groupe Facebook** : https://www.facebook.com/groups/1451283625021958  
🎬 **Chaîne YouTube** : https://www.youtube.com/@lespremieresnationsauquebec

## Nations couvertes
- Abénaquis
- Algonquins
- Atikamekw
- Cris
- Hurons-Wendat
- Innus
- Inuits (Nunavik)
- Malécites
- Micmacs
- Mohawks
- Naskapis

## Structure du projet
- `pages/` — Pages React/JSX de chaque nation
- `pages/Home.jsx` — Page d'accueil avec grille de navigation
- `pages/Videos.jsx` — Médiathèque vidéos YouTube
- `pages/Audio.jsx` — Médiathèque audio (à venir)

## Mission
Rétablir la vérité sur les peuples autochtones, contrer les stéréotypes, et partager leur histoire millénaire avec respect et rigueur.
